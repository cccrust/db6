# v4.1 - Pub/Sub 發布/訂閱模式

## 日期：2026-05-17

## 目標

在現有的 msgq 模組中新增 Pub/Sub 功能，支援一訊息多訂閱者（broadcast）。

## 差異說明

| 特性 | Queue（佇列） | Pub/Sub（發布/訂閱） |
|------|--------------|---------------------|
| 訊息歸屬 | 一個 consumer 取走後其他人看不到 | 所有訂閱者都能收到 |
| 處理模型 | FIFO，一次取走 | Broadcast，複製給所有人 |
| 確認機制 | ack/nack | 無需 ack（廣播模式） |
| 適用場景 | 工作排程 | 通知、事件廣播 |

## Key 設計

```
pubsub:{channel}:messages    -> 訊息列表（append-only）
pubsub:{channel}:subscribers -> 訂閱者列表
pubsub:{channel}:offset:{subscriber_id} -> 訂閱者偏移量
```

### Message 結構（复用現有）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PubSubMessage {
    pub id: String,
    pub channel: String,
    pub payload: Vec<u8>,
    pub timestamp: u64,
}
```

## API 設計

```rust
pub struct PubSub {
    engine: Arc<RwLock<KvEngine>>,
}

impl PubSub {
    /// 建立 PubSub 實例
    pub fn new(engine_type: &str) -> Result<Self>;

    /// 發布訊息到頻道
    pub fn publish(&mut self, channel: &str, payload: Vec<u8>) -> Result<String>;

    /// 訂閱頻道
    pub fn subscribe(&mut self, channel: &str, subscriber_id: &str) -> Result<()>;

    /// 取消訂閱
    pub fn unsubscribe(&mut self, channel: &str, subscriber_id: &str) -> Result<()>;

    /// 消費訊息（取得新訊息）
    pub fn consume(&mut self, channel: &str, subscriber_id: &str) -> Result<Option<PubSubMessage>>;

    /// 列出所有頻道
    pub fn list_channels(&self) -> Result<Vec<String>>;

    /// 列出頻道的訂閱者
    pub fn list_subscribers(&self, channel: &str) -> Result<Vec<String>>;

    /// 取得頻道訊息數
    pub fn message_count(&self, channel: &str) -> Result<usize>;
}
```

## 使用範例

```rust
use db6::msgq::PubSub;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut ps = PubSub::new("memory")?;

    // 訂閱者 A 訂閱 "notifications" 頻道
    ps.subscribe("notifications", "subscriber_A")?;

    // 訂閱者 B 訂閱 "notifications" 頻道
    ps.subscribe("notifications", "subscriber_B")?;

    // 發布訊息
    let msg_id = ps.publish("notifications", b"Hello all subscribers!")?;
    println!("Published: {}", msg_id);

    // 訂閱者 A 消費
    let msg_a = ps.consume("notifications", "subscriber_A")?;
    println!("A received: {:?}", msg_a.payload_str());

    // 訂閱者 B 消費（同一則訊息）
    let msg_b = ps.consume("notifications", "subscriber_B")?;
    println!("B received: {:?}", msg_b.payload_str());

    Ok(())
}
```

## 實作細節

### 1. 訊息儲存

```rust
/// 頻道訊息列表
#[derive(Serialize, Deserialize)]
struct ChannelMessages {
    messages: Vec<PubSubMessage>,
}
```

- 新訊息 push 到 `messages` 陣列末端
- 每個訂閱者有獨立的 offset

### 2. 訂閱者offset追蹤

```rust
/// 訂閱者偏移量
struct SubscriberOffset {
    subscriber_id: String,
    offset: usize,  // 已讀到的訊息位置
}
```

### 3. consume 邏輯

```rust
fn consume(&mut self, channel: &str, subscriber_id: &str) -> Result<Option<PubSubMessage>> {
    // 1. 取得訂閱者 offset
    let offset = self.get_offset(channel, subscriber_id)?;

    // 2. 取得頻道所有訊息
    let messages = self.get_channel_messages(channel)?;

    // 3. 若 offset < messages.len()，回傳訊息並 increment offset
    if offset < messages.len() {
        let msg = messages[offset].clone();
        self.set_offset(channel, subscriber_id, offset + 1)?;
        return Ok(Some(msg));
    }

    // 無新訊息
    Ok(None)
}
```

## 測試案例

```rust
#[test]
fn test_pubsub_basic() {
    let mut ps = PubSub::new("memory").unwrap();

    // 訂閱
    ps.subscribe("news", "reader1").unwrap();
    ps.subscribe("news", "reader2").unwrap();

    // 發布
    let id = ps.publish("news", b"Breaking news!").unwrap();
    assert!(!id.is_empty());

    // 兩訂閱者都能收到
    let msg1 = ps.consume("news", "reader1").unwrap().unwrap();
    let msg2 = ps.consume("news", "reader2").unwrap().unwrap();

    assert_eq!(msg1.payload, b"Breaking news!");
    assert_eq!(msg2.payload, b"Breaking news!");
    assert_eq!(msg1.id, msg2.id); // 同一則訊息
}

#[test]
fn test_pubsub_offset_tracking() {
    let mut ps = PubSub::new("memory").unwrap();

    ps.subscribe("ch", "sub").unwrap();

    ps.publish("ch", b"msg1").unwrap();
    ps.publish("ch", b"msg2").unwrap();

    // 讀取第一則
    let m1 = ps.consume("ch", "sub").unwrap().unwrap();
    assert_eq!(m1.payload, b"msg1");

    // 讀取第二則
    let m2 = ps.consume("ch", "sub").unwrap().unwrap();
    assert_eq!(m2.payload, b"msg2");

    // 沒有第三則
    let m3 = ps.consume("ch", "sub").unwrap();
    assert!(m3.is_none());
}

#[test]
fn test_pubsub_unsubscribe() {
    let mut ps = PubSub::new("memory").unwrap();

    ps.subscribe("ch", "sub").unwrap();
    ps.publish("ch", b"msg").unwrap();

    // 訂閱者可收到
    assert!(ps.consume("ch", "sub").unwrap().is_some());

    // 取消訂閱
    ps.unsubscribe("ch", "sub").unwrap();

    // 重新訂閱後，從頭開始
    ps.subscribe("ch", "sub").unwrap();
    let msg = ps.consume("ch", "sub").unwrap().unwrap();
    assert_eq!(msg.payload, b"msg");
}

#[test]
fn test_pubsub_list_channels() {
    let mut ps = PubSub::new("memory").unwrap();

    ps.subscribe("ch1", "sub").unwrap();
    ps.publish("ch2", b"msg").unwrap();

    let channels = ps.list_channels().unwrap();
    assert!(channels.iter().any(|c| c == "ch1"));
    assert!(channels.iter().any(|c| c == "ch2"));
}
```

## 與 Queue 的整合

可選擇：
1. **獨立運作** — PubSub 和 Queue 完全分開
2. **統一介面** — Msgq 同時支援 queue 和 pubsub

建議採用方案 2，在 Msgq 中新增 pubsub() 方法：

```rust
pub struct Msgq {
    engine: Arc<RwLock<KvEngine>>,
}

impl Msgq {
    pub fn queue(&self, name: &str) -> Queue { ... }
    pub fn pubsub(&self) -> PubSub { ... }
}
```
