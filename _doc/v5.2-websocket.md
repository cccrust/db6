# v5.3 WebSocket Transport

## Overview

Added WebSocket support for bidirectional, real-time communication with db6 server.

## Features

- Real-time request/response over WebSocket
- JSON-based protocol
- Single connection for multiple operations
- Compatible with Python/Node.js WebSocket clients

## API

### WebSocket Endpoint

`ws://localhost:50052/ws`

### Request Format

```json
{
  "method": "kv_put",
  "id": 1,
  "params": {
    "table_id": 1,
    "key": "test",
    "value": "hello"
  }
}
```

### Response Format

```json
{
  "id": 1,
  "result": { "status": "ok" },
  "error": null
}
```

## Supported Methods

| Method | Description |
|--------|-------------|
| `health` | Health check |
| `kv_put` | Put a key-value pair |
| `kv_get` | Get value by key |
| `kv_delete` | Delete a key |
| `kv_scan` | Range scan [start, end) |
| `kv_batch_put` | Batch write multiple pairs |
| `kv_stats` | Get engine statistics |

## Python Example

```python
import json
import asyncio
import websockets

async def main():
    uri = "ws://localhost:50052/ws"
    async with websockets.connect(uri) as ws:
        # Put
        await ws.send(json.dumps({
            "method": "kv_put",
            "id": 1,
            "params": {"table_id": 1, "key": "test", "value": "hello"}
        }))
        resp = json.loads(await ws.recv())
        print(resp)

        # Get
        await ws.send(json.dumps({
            "method": "kv_get",
            "id": 2,
            "params": {"table_id": 1, "key": "test"}
        }))
        resp = json.loads(await ws.recv())
        print(resp)

asyncio.run(main())
```

## Node.js Example

```javascript
const WebSocket = require('ws');

const ws = new WebSocket('ws://localhost:50052/ws');

ws.on('open', () => {
  // Put
  ws.send(JSON.stringify({
    method: 'kv_put',
    id: 1,
    params: { table_id: 1, key: 'test', value: 'hello' }
  }));
});

ws.on('message', (data) => {
  console.log(JSON.parse(data));
  ws.close();
});
```
