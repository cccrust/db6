# v0.2 - KV Core Implementation Status

## 2026-05-16

## 完成項目

### StorageEngine Trait
- [x] Dyn-compatible trait with `where Self: Sized` bounds
- [x] Methods: `open`, `open_memory`, `get`, `put`, `delete`, `scan`, `flush`, `sync`
- [x] Transaction methods: `begin_transaction`, `commit_transaction`, `rollback_transaction`, `has_transaction`
- [x] Stats: `engine_type`, `stats()`

### Memory Engine (v0.1)
- [x] BTreeMap-based storage
- [x] Multi-table support via table_id
- [x] Range scan with `std::collections::Bound`
- [x] Returns NotSupported for transactions (as designed)

### BTree Engine (v0.2)
- [x] BTree-based storage (simplified BTreeMap implementation)
- [x] Full transaction support (begin/commit/rollback)
- [x] Transaction buffer for uncommitted changes
- [x] Thread-safe with RwLock

### KV Module
- [x] KvStore trait (core operations)
- [x] Transactional trait (optional)
- [x] Persistent trait (optional)

### Tests
- [x] 5 memory engine tests passing
- [x] 5 btree engine tests passing

## 架構說明

```
User API
  |
  +-- KvStore (unified KV interface)
  |     +-- MemoryEngine (BTreeMap, in-memory)
  |     +-- BTreeEngine (BTree, in-memory, transaction support)
  |     +-- LsmEngine (LSM-tree, needs impl)
```
