# v5.0 gRPC / HTTP Service

## Overview

Added a network transport layer to expose db6 functionality via HTTP/2 JSON API.

## Architecture

```
src/
  grpc_server.rs    # HTTP/2 JSON API server binary
  grpc/
    proto/
      db6.proto     # Protocol Buffers definitions
      generated/
        db6.rs      # Generated message types (via prost-build)
    mod.rs          # Empty module placeholder
```

## Implementation

Since `tonic-build` 0.14 removed the `configure()` API (deprecated in 0.11), we use:
- **prost-build** for proto message type generation
- **axum** for HTTP/2 JSON API

This provides network access to db6 without requiring gRPC code generation.

## API Endpoints

All endpoints use JSON request/response over HTTP/2 on port 50051.

### KV Operations

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /kv/put | Put a key-value pair |
| POST | /kv/get | Get a value by key |
| POST | /kv/delete | Delete a key |
| POST | /kv/scan | Range scan [start, end) |
| POST | /kv/batch_put | Batch write multiple pairs |
| GET | /kv/stats | Get engine statistics |

### Request/Response Format

```json
// POST /kv/put
{
  "table_id": 1,
  "key": "user:123",
  "value": "{\"name\": \"John\"}"
}

// Response
{
  "status": "ok"
}
```

## Usage

```bash
# Build
cargo build --bin grpc-server

# Run server
cargo run --bin grpc-server
# Output: HTTP/JSON server listening on http://127.0.0.1:50051

# Test
curl -X POST http://127.0.0.1:50051/kv/put \
  -H "Content-Type: application/json" \
  -d '{"table_id": 1, "key": "test", "value": "hello"}'

curl http://127.0.0.1:50051/kv/stats
```
